# Art set C — plan

**Status:** Draft for the user's approval. No PixelLab generations spent yet.
**Date:** 2026-11-17

## Intent

Art set A works but is off from the reference board (`docs/reference/mvp-board.png`, local only). Art set B was a first, quick try at the board's look and has known faults (body three-quarter from behind, chair painted into the character, a narrow window, shoes cropped). Set C is the reference board done properly, as a complete swappable set, built through the full workflow: PixelLab draft → Aseprite → export. It is chosen with `-artSet C`; A stays the default until the user decides otherwise.

## Composition (the one decision everything follows from)

A side view of a desk against the wall, the character in **side profile, half-body, seated behind the desk**, facing left toward the monitor. **The desk front hides the lower body.** That makes the desk front the only occluder (a simple shape), and the chair sits behind the body, so poses never have to be cut out of a chair (the problem in A and B).

Rough layout on the 480×352 canvas (safe area 452×328, inset 14 left/right and 12 top/bottom):

```
+------------------------------------------------------------------+
| string lights                                       poster       |
|  +-----------------------+    shelf: books, plant, lantern       |
|  |  wide window          |                                       |
|  |  (key-colour glass)   |   lamp   [monitor]                    |
|  |                       |    \     [ code ]   (character, side  |
|  +-----------------------+    clock  mug  kb   profile, behind   |
|  sill: cat cushion        ===========DESK FRONT===========  desk)|
|  floor                     drawers                          bed  |
+------------------------------------------------------------------+
```

Anchors and hotspots are fixed by the room picture once it exists: `desk-seat` (behind the desk), `pet-spot` (cushion on the sill or desk), `clock-slot` (blank clock face on the desk), `lamp`, `computer`, `window-rect` / `window-mask` (the glass), and the music frame on free wall.

## Lessons from A and B, applied to every prompt

- Glass filled with one flat key colour that appears nowhere else in the room (B's green clashed with green code on the monitor; A's magenta worked).
- Enough floor and ceiling margin that nothing important sits outside the safe area (B lost 8 rows of shoes).
- An empty chair, an empty cat spot, and a clock with a blank screen in the room picture; no people, no animals.
- Cities: "full-bleed, edge to edge, no window frame, no interior" (asking for a view "from a window" draws a frame).
- Characters and poses as edits of the same crop, so scale, light and seat stay consistent.
- Every colour of hand-drawn parts (music skin, rain, clock) sampled from the room (the walnut-radio lesson).
