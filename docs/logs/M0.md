# M0 — Visual + energy proof of concept

**Status:** Implemented and verified on device; energy/CPU baseline still to be measured by hand (see Open issues). Awaiting approval before M1.
**Scope:** see `CLAUDE.md` › Current milestone and `docs/spec/LOCKED_MVP_SPEC.md` §9.
**Date:** 2026-11-14

## Environment

- Xcode 27.1 (27A9275), Swift 6.3.3, iOS SDK 27.1. `xcode-select` points at the Command Line Tools, so every command needs `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`.
- Test device: iPad Pro 11-inch (3rd gen, M1), iPadOS 27.0.1, device ID in `CLAUDE.local.md`. No simulator is used (user decision).
- Signing: free Personal Team (ID in `CLAUDE.local.md`), bundle ID `com.lofiroom.app`. Free profiles cap the number of installed dev apps and expire after 7 days.
- XcodeGen 2.46.0 generates `LoFiRoom.xcodeproj` from `project.yml` (the project file is git-ignored).

## Decisions

> Superseded in M1: the canvas safe rectangle is now 452×328 (5× on the 11-inch), sprites anchor bottom-left, and placeholders were replaced by PixelLab art. See `M1.md`.

- **Canvas (hypothesis, spec §2.3):** 480×352 logical px bleed canvas, 384×256 safe rectangle, largest integer scale that fits the safe rectangle. Measured on the 11-inch: 6× (visible area 398×278 logical px). Unit-tested values: 12.9-inch → 7×, portrait-shaped window → 4×.
- **Landscape (review B1):** `UIRequiresFullScreen = true` plus landscape-only orientations. Without the key, iPadOS 27.0.1 ran the app in portrait (seen on device); with it the app runs landscape. The key is deprecated, so this is a stop-gap. Other window shapes get a letterbox; no portrait art will be made (user decision).
- **Anchors:** all 7 IDs live in `LoFiRoom/Assets/anchors.json`; origin bottom-left; every anchor must be inside the safe rectangle (enforced by `AnchorManifest.validate()`). `desk-seat` is the character's feet on the floor under the chair; character sprites are bottom-centre registered on it.
- **Placeholders:** flat blocks from `Tools/make_placeholders.py`, which also writes `anchors.json`. PixelLab was not used in M0.
- **Deployment target:** iPadOS 26.0.
- **Measurement switches:** launch arguments `-fps N`, `-paused YES`, `-debugAnchors YES` (overlay + FPS counter). No settings UI.

## Done

- SwiftUI app shell → `SceneContainer` (wrapped `SKView`) → `LoFiSKScene` (scenery, room, cat, boy; no `update` loop, no physics).
- `CharacterNode`: 2-frame study loop at 2 fps.
- `ScalePolicy`, `AnchorManifest`, `PixelTexture` (forces nearest filtering).
- 5 unit tests.

## Build / test / profiling results (all on the physical iPad)

- `xcodebuild test … -destination platform=iOS,id=<UDID>`: `Executed 5 tests, with 0 failures` / `** TEST SUCCEEDED **`.
- Screenshots via `devicectl device capture screenshot`: 2388×1668, room fills the screen at 6×, edges hard at 1:1 (no blur), anchors land on the lamp, cat, monitor, clock bezel, window and feet.
- Portrait window (before the full-screen key): safe scene letterboxed at 4×, black bars, no re-composition.
- SpriteKit FPS counter read 30.0, 12.0 and 6.0 for `-fps 30/12/6`, so the requested rates are honoured on the 120 Hz panel.
- Console noise: CoreUI logs "unable to find a bundle … with identifier" when loading loose PNGs. Harmless; goes away when art moves into `.spriteatlas` (M1).

## Open issues

1. **No trustworthy CPU/energy numbers yet.** `xctrace record --template 'Activity Monitor' --device … --all-processes` stopped after about 1 s whatever `--time-limit` was given, and `--attach` could not find the process. The 1-second snapshots that did come back read about 5 % of one core, about 104 MiB and about 61 wakeups/s for 30 fps, 6 fps and paused alike. Identical numbers across settings mean the window is too short or mostly launch cost, so they are **not** a baseline.
2. To do by hand in Instruments (Activity Monitor + Energy Log), per spec §8.1 scenarios 1–2: `-paused YES`, then `-fps 30`, `-fps 12`, `-fps 6`; 10 min warm-up, 30 min each, fixed brightness, auto-brightness and True Tone off. Check in particular whether wakeups really stay near 60/s when paused.
3. 104 MiB footprint for five tiny textures looks high; confirm in the long run before judging.
4. `UIRequiresFullScreen` is deprecated; revisit if a future iPadOS drops it.
5. Placeholder composition is rough (desk and figure proportions). Real art direction starts with PixelLab in M1.
